# lm75-guide

Учебный драйвер датчика температуры LM75 на `embedded-hal` 1.0. Разбор кода находится в [главе 5](../../book/05-writing-lm75.md), тесты разбираются в [главе 6](../../book/06-testing.md).

```sh
cargo test
```

Драйвер умеет читать температуру, а также включать и выключать режим энергосбережения. Он не зависит от платы и работает с любой реализацией трейта `embedded_hal::i2c::I2c`.

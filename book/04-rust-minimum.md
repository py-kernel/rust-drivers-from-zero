# Глава 4. Минимум Rust для драйверов

Эта глава не заменяет книгу по Rust. Здесь собрано только то, что встретится в коде драйвера. Если какое-то понятие знакомо, раздел можно пропустить.

## Result и оператор ?

Операция с шиной может завершиться неудачей. В Rust такая операция возвращает `Result`. Это тип с двумя вариантами: `Ok(значение)` и `Err(ошибка)`.

```rust
fn read_byte() -> Result<u8, MyError> {
    // ...
}

fn use_it() -> Result<(), MyError> {
    let byte = read_byte()?;
    // здесь byte - обычное число u8
    Ok(())
}
```

Знак `?` после вызова означает следующее. Если пришло `Ok`, достать значение и продолжить. Если пришло `Err`, немедленно выйти из функции и вернуть эту ошибку. Без `?` пришлось бы писать `match` после каждого вызова.

Иногда тип ошибки нужно заменить. Для этого служит метод `map_err`.

```rust
self.i2c.write(addr, &bytes).map_err(Error::I2c)?;
```

Здесь `Error::I2c` - это вариант перечисления, но одновременно и функция. Она принимает ошибку шины и заворачивает её в `Error::I2c(...)`. Метод `map_err` применяет эту функцию, если результат оказался ошибкой.

## Структуры и impl

Структура объединяет данные. Блок `impl` добавляет к ней функции.

```rust
pub struct Lm75<I2C> {
    i2c: I2C,
    address: Address,
}

impl<I2C: I2c> Lm75<I2C> {
    pub fn new(i2c: I2C, address: Address) -> Self {
        Lm75 { i2c, address }
    }
}
```

Функция `new` принимает шину по значению. В Rust это означает передачу владения. После вызова `Lm75::new(i2c, ...)` переменная `i2c` в вызывающем коде больше недоступна, шина целиком принадлежит драйверу. Благодаря этому два драйвера не смогут одновременно писать в одну шину по ошибке.

Что делать, если шина нужна другому коду, показывает метод `destroy`. Он забирает драйвер целиком и возвращает шину обратно. Для нескольких датчиков на одной шине существует отдельный крейт `embedded-hal-bus`, о нём пойдёт речь в плане дальнейших глав.

## Дженерики и трейты

Запись `Lm75<I2C>` означает: структура работает с любым типом шины, и этот тип обозначен именем `I2C`. Имя выбрано произвольно, это просто заглушка вроде `T`.

Запись `impl<I2C: I2c>` накладывает ограничение. Тип должен реализовывать трейт `I2c`. Если передать что-то другое, компилятор откажет на этапе сборки и назовёт причину.

Для драйвера это ключевая конструкция. Он не обращается к конкретному чипу. Он просит "что-нибудь, что умеет работать с I2C", и в пользовательском проекте это окажется шиной Pico, ESP32 или STM32. В тестах на её месте стоит заглушка.

## Ассоциированные типы

Разные шины возвращают разные ошибки. Поэтому тип ошибки задан не в драйвере, а в самой шине. В трейте это выглядит как ассоциированный тип `Error`. Обратиться к нему можно так.

```rust
Result<i16, Error<I2C::Error>>
```

Читается так: "ошибка того типа, который объявила выбранная шина".

## Изменяемая ссылка

Почти все методы драйвера принимают `&mut self`. Это изменяемая ссылка на драйвер. Она нужна потому, что чтение с шины меняет состояние шины, даже если датчик при этом не меняется. Трейт `I2c` требует `&mut self` у всех своих методов, и по цепочке это требование доходит до драйвера.

## Массивы и срезы

```rust
let mut buffer = [0u8; 2];
```

Массив из двух байтов, оба равны нулю. Запись `0u8` означает "число 0 типа `u8`".

Методы шины принимают срезы, то есть "окна" над последовательностью байтов. Срез записывается как `&[u8]` (только чтение) или `&mut [u8]` (чтение и запись). Компилятор сам преобразует `&mut buffer` в срез. Литерал `&[register::TEMPERATURE]` создаёт срез из одного элемента.

Шина заполняет `buffer` принятыми байтами. Поэтому он объявлен как `mut`, а передаётся как `&mut buffer`.

## Целые числа и сдвиги

В драйвере встречаются три операции с числами.

**Сборка числа из байтов.** Метод `i16::from_be_bytes([старший, младший])` собирает знаковое 16-битное число. Суффикс `be` означает big-endian: первым идёт старший байт. Именно так передаёт данные LM75.

**Сдвиг вправо.** Запись `x >> 5` сдвигает биты на пять позиций. Для знаковых чисел сдвиг арифметический: старший бит (знак) копируется в освободившиеся места, и отрицательное число остаётся отрицательным. Для беззнаковых сдвиг логический: освобождающиеся места заполняются нулями. Типы `i16` и `u16` ведут себя здесь по-разному. Это различие имеет прямое отношение к температурам ниже нуля.

**Преобразование в дробное число.** Выражение `f32::from(raw)` превращает `i16` в `f32` без потерь. Для такого преобразования в Rust есть безопасный способ `From`, и он предпочтительнее приведения через `as`, потому что компилятор проверяет отсутствие потерь.

## no_std

На микроконтроллере нет операционной системы, поэтому нет файлов, консоли и, как правило, динамической памяти. Стандартная библиотека `std` рассчитана на всё это. Атрибут `#![no_std]` в начале `lib.rs` отключает её, и остаётся `core` - подмножество, которое работает везде.

Без `std` недоступны `Vec`, `String`, `Box`, `println!` и `format!`. Массивы, срезы, `Option`, `Result`, числа и итераторы остаются.

## Замыкания

Метод `modify_configuration` принимает функцию, которая получает старое значение регистра и возвращает новое.

```rust
fn modify_configuration(
    &mut self,
    change: impl FnOnce(u8) -> u8,
) -> Result<(), Error<I2C::Error>> {
    // ...
}

self.modify_configuration(|config| config | SHUTDOWN_BIT)
```

Конструкция `|config| config | SHUTDOWN_BIT` - это замыкание, то есть безымянная функция. Первая пара вертикальных черт `|config|` обрамляет список параметров. Вторая черта в выражении `config | SHUTDOWN_BIT` - операция побитового ИЛИ. Здесь их легко принять за одно и то же, но это разные знаки.

Запись `impl FnOnce(u8) -> u8` означает "любая функция, которая принимает `u8`, возвращает `u8` и вызывается один раз".

## Побитовые операции

В драйвере используются три операции.

| Запись | Значение | Пример |
|---|---|---|
| `a \| b` | ИЛИ, бит равен 1, если он равен 1 хотя бы в одном числе | `0b0001_0000 \| 0b0000_0001 = 0b0001_0001` |
| `a & b` | И, бит равен 1, только если он равен 1 в обоих числах | `0b0001_0001 & 0b1111_1110 = 0b0001_0000` |
| `!a` | НЕ, все биты инвертируются | `!0b0000_0001 = 0b1111_1110` для `u8` |

Чтобы установить бит, применяется ИЛИ с маской. Чтобы сбросить бит, применяется И с инвертированной маской. Остальные биты числа в обоих случаях не меняются.

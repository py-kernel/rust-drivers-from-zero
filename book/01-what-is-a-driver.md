# Глава 1. Что такое драйвер

Датчик температуры LM75 - маленькая микросхема. Внутри неё находятся термометр и несколько ячеек памяти, которые называются регистрами. Микроконтроллер ничего не знает об этих ячейках заранее. Он умеет одно: отправлять и принимать байты по шине.

Драйвер - это код, который знает, какие байты отправить и как понять полученные. Для остальной программы он выглядит так.

```rust
let celsius = sensor.read_temperature()?;
```

Одна строка. За ней стоят адрес устройства на шине, номер регистра, два принятых байта, битовый сдвиг и умножение. Без драйвера всё это пришлось бы повторять в каждой программе, и каждый раз заново искать в ней ошибки.

## Где драйвер находится в программе

Программа для микроконтроллера состоит из слоёв. Верхний слой знает, что нужно сделать. Нижний слой знает, как управлять конкретным кристаллом. Между ними нужен посредник, иначе код для одной платы нельзя будет перенести на другую.

```
программа пользователя
          |
     драйвер LM75           <- этот слой мы пишем
          |
   трейты embedded-hal      <- общий язык: "шина I2C", "вывод", "задержка"
          |
   HAL конкретного чипа     <- rp-hal, esp-hal, stm32f4xx-hal и другие
          |
        железо
```

Драйвер обращается только ко второму слою. Он не знает, какой чип под ним: Raspberry Pi Pico, ESP32 или STM32. Ему известно лишь, что есть нечто, умеющее выполнять операции шины I2C. Поэтому один и тот же драйвер работает на всех платах.

## Что такое embedded-hal

`embedded-hal` - крейт, в котором нет ни одной реализации. В нём описаны только трейты. Трейт в Rust - это список возможностей. Например, трейт `I2c` говорит, что тип умеет читать с шины, писать на шину и делать обе операции подряд.

Каждый производитель чипов (точнее, сообщество вокруг него) пишет свой HAL и реализует эти трейты для своих шин. Автор драйвера пишет код против трейтов. Пользователь подставляет шину своей платы.

Версия 1.0 вышла на рубеже 2023 и 2024 годов. С этого момента ветка 1.x считается стабильной, то есть код, написанный под 1.0, продолжит собираться с более поздними выпусками 1.x. До этого существовала ветка 0.2 с другими трейтами. Многие материалы в сети описывают именно её. Их примеры не соберутся с версией 1.0 без изменений, и это стоит иметь в виду при поиске ответов в интернете.

## Что понадобится

Компьютер с установленным Rust. Плата для первых глав не нужна. Логика драйвера проверяется тестами на обычном компьютере, и [глава 6](06-testing.md) показывает, как это устроено. Работа с настоящим датчиком идёт отдельной главой в конце.

## Словарь

**Шина.** Набор проводов, по которым устройства обмениваются данными. Здесь используется шина I2C.

**Регистр.** Ячейка памяти внутри микросхемы. У каждого регистра есть номер. Одни регистры можно читать, другие можно и читать, и записывать.

**Datasheet.** Документ производителя микросхемы. В нём описаны выводы, адреса, регистры и форматы данных. Драйвер пишется по нему.

**HAL.** Hardware Abstraction Layer, слой, который прячет различия между чипами.

**Трейт.** Описание набора возможностей, которые тип обязан предоставить.

**Крейт.** Библиотека или программа на Rust. Крейт - единица, которую публикуют на crates.io.

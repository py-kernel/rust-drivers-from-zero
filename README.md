# Драйверы на Rust с нуля

Пошаговое руководство по написанию драйверов для микроконтроллеров на Rust. Каждый шаг объясняется подробно, а плата для первых глав не нужна.

Руководство отвечает на вопрос, который стоит в описании организации py-kernel. Порог входа в embedded-программирование выше, чем нужно, и часть этой высоты создана плохими объяснениями. Здесь объяснения подробные.

Готовый код находится в [`examples/lm75`](examples/lm75).

## Быстрый старт

```sh
git clone <адрес репозитория>
cd rust-drivers-from-zero/examples/lm75
cargo test
```

Если Rust ещё не установлен, начните с [главы 2](book/02-setup.md).

## Версии

Код проверен с такими версиями.

| Компонент | Версия |
|---|---|
| `embedded-hal` | 1.0.0 |
| `embedded-hal-mock` | 0.11.1 |
| `rustc` | 1.75.0 |

Версия `embedded-hal` 1.0 стабильна. Код, написанный под неё, продолжит собираться со всеми выпусками 1.x. Старые материалы по `embedded-hal` 0.2 описывают другие трейты, и их примеры без переделки не заработают.

## Статус

Готовы главы 1-6 и один драйвер. Главы про работу с настоящей платой, AHT20, MPU6050, SSD1306 и SPI запланированы. Подробности в [главе 7](book/07-next.md).
